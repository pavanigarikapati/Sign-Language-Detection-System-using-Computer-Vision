# Sign-Language-Detection-System-using-Computer-Vision
Sign Language Detection System using Computer Vision is a real-time gesture recognition project that converts hand signs into readable text using computer vision. Built with OpenCV and MediaPipe, it detects and tracks hand movements to provide an accessible, hardware-free solution for improving communication.


## Overview
This project presents a real-time Sign Language Detection System developed using Computer Vision techniques. The system detects and recognizes hand gestures through a webcam and converts them into understandable output. It aims to reduce communication barriers and support inclusive interaction for Deaf and hard-of-hearing communities.

## Features
- Real-time hand gesture detection
- Vision-based approach without wearable devices
- Hand landmark extraction using MediaPipe
- Gesture recognition and classification
- Lightweight and easy-to-run implementation
- Supports future extension for dynamic gestures

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Machine Learning / CNN

## Methodology
1. Capture live video using webcam
2. Detect hand landmarks
3. Extract gesture features
4. Classify gestures
5. Display predicted output

## Project Workflow
Camera Input → Hand Detection → Feature Extraction → Gesture Classification → Output Display
